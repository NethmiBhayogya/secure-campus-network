Day 1: Secure University Campus Network

Project Overview
This project aims to design and implement a secure university campus network using Cisco Packet Tracer.

The network will simulate a main campus and a branch campus, supporting different university departments, staff, students, and IT services.

Objectives
- Design a scalable campus network topology.
- Separate departments using VLANs.
- Configure inter-VLAN routing.
- Provide automatic IP address allocation using DHCP.
- Establish routing between the main and branch campuses.
- Implement SSH for secure device management.
- Apply switch Port Security.
- Configure wireless connectivity.
- Use Access Control Lists (ACLs) to control network traffic.
- Test connectivity and troubleshoot network problems.

Planned Technologies
- Cisco Packet Tracer
- IPv4 addressing and subnetting
- VLANs and trunk links
- Inter-VLAN routing
- DHCP
- RIPv2
- SSH
- Port Security
- Wireless LAN
- Access Control Lists (ACLs)

Learning Goals
By completing this project, I aim to strengthen my practical knowledge of routing, switching, IP addressing, network security, and troubleshooting.
