# Day 1: VLAN Plan

## Overview
This file describes the planned VLANs for the Secure University Campus Network project. VLANs will help separate different types of users and network devices.

## Planned VLANs

| VLAN ID | VLAN Name | Network |
|---|---|---|
| 10 | ADMIN | 10.10.10.0/24 |
| 20 | FINANCE | 10.10.20.0/24 |
| 30 | STUDENTS | 10.10.30.0/24 |
| 40 | IT | 10.10.40.0/24 |
| 50 | SERVERS | 10.10.50.0/24 |
| 60 | GUEST_WIFI | 10.10.60.0/24 |

## Purpose
- VLAN 10: Administration staff
- VLAN 20: Finance department
- VLAN 30: Student computers
- VLAN 40: IT department
- VLAN 50: University servers
- VLAN 60: Guest wireless users

## Status
The VLANs are planned but have not yet been configured or tested in Packet Tracer.
